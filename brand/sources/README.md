# sources/

Reference images for the photographic icon candidates, kept so
`gen-icon-cutouts.py` can be re-run. Filenames are descriptive, not titles.

| File | What it is |
| --- | --- |
| `rimbust.png` | Faceless bust, rim-lit warm and cool on a dark ground |
| `greenglass.png` | Liquid-glass bust in green |
| `crystal.png` | Crystalline figure, sparkle highlights, black ground |
| `spartan.png` | Crystal warrior in a plumed helmet, numerals behind |
| `eyes.png` | White glowing figure, hands raised |
| `xray.png` | White filament creature, single amber eye |
| `blueghost.png` | Glowing figure in a crowd, heavy grain |
| `disco.png` | Mirrored figure driving, code across the sky |

## Read this before shipping one

**These are found images with no known licence.** They arrived as a moodboard
and were kept because the generators need an input, not because rights were
cleared. Using one as the published logo of a product that touches money is a
real exposure, not a theoretical one — and a repo this sits in may be public.

They are the right tool for locking a direction. Before launch, replace the
chosen one with a render that is yours: commissioned, or generated from your
own prompt. The treatment survives the swap — `gen-icon-cutouts.py` takes any
image, and the framing table at the bottom of it is the only thing that needs
retuning.
